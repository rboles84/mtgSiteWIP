How These References Are Used

How public references support the site.

This is the short version: what each reference type helps with, and where Vox Mana draws the line between public evidence and private drafting work.

Official Lore

Baseline authority

Official lore is treated as the strongest foundation for named events, faction voice, and continuity.

Community References

Interpretation support

Community references help clarify structure, compare readings, and show how players commonly understand the lore.

Video Lore

Review and cross-checking

Video sources are used as review surfaces and cross-check aids, not as standalone canon.

Archives And Indexes

Navigation and continuity

GitHub archives, story indexes, and public collections help track story material and keep continuity easier to follow.

Internal notes and generated research files help with drafting, but they are not treated as public source authority.

Phase 2: Research Vault

A later vault can hold the larger working collection.

This page is intentionally focused on public URLs. A later vault can surface or summarize the larger working collection without turning the public reference page into a file dump.

Vox Mana also has a broader working research collection: PDFs, RTF files, Markdown notes, HTML captures, generated lore summaries, validation notes, and faction research bundles. Those files are valuable, but they need a separate design so they stay useful instead of overwhelming the main library.

What Is Not Published

Public references are here. Private system details are not.

This page lists public references and explains how they are used. It does not publish the private scoring or drafting machinery behind Vox Mana.

Apocrypha shows public links, reference categories, and short usage notes. It does not publish private scoring logic, prompt internals, or unpublished working notes.
