Magic Basics

Start with the system.

Magic is a strategy card game built around five colors of mana. Each color is more than a deck style: it is a philosophy, a way of solving problems, and a lens for identity and story.

This homepage should make the purpose obvious: learn the color system, find your placement, search symbolic card meaning, or read deeper lore.
