# Precon reference provenance

The files in this directory are preserved research and editorial provenance. They are not runtime input and must not be treated as canonical product copy.

`../vox-mana-precons.source.json` is the canonical precon source. Its reviewed wording supersedes comparative, ranking, consensus, or other editorial language retained in these reference files. Runtime artifacts must be rebuilt from that JSON with `npm.cmd run build:precons`; do not reimport reference wording over the canonical source.

The reference CSV and archived workbook remain unchanged so their historical research context can be audited.
