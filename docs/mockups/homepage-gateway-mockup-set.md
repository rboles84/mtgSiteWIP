## Direction

The home page should stay a three-door gateway with a central Maze presence, Archscry as the guided reading door, and Apocrypha as a visible published destination. The layout should feel like a carved chamber with real product controls embedded into the architecture.

The strongest signals from the reference set are:

- a centered, ceremonial Maze mass
- left and right destination cards that feel like actual doors
- a compact right-side quote or observation rail
- a bottom status strip for context and recency
- gold-and-teal illumination on black stone
- bronze linework, thin borders, and restrained shadows
- readable hierarchy instead of decorative clutter

## Frames

### Frame 01 - First Visit Desktop

- 1440px desktop composition
- hero text on the left
- Maze dominant in the center
- Archscry and Apocrypha both visible and active
- a clear start action for the gateway
- a premium but readable home threshold

### Frame 02 - Returning User Desktop

- 1440px desktop composition
- compact resume chip or return panel integrated into the gateway
- current active reading shown without turning the home into a dashboard
- previous reading or recent Maze path cues kept lightweight
- start-new-reading action still available

### Frame 03 - Mobile Gateway

- 390px mobile composition
- preserve the same destination hierarchy in a compressed form
- use stacked destination cards without losing premium feel
- keep the resume affordance and top-level navigation legible
- avoid a flat vertical wall of cards or text

## Copy And UI Notes

- Keep Apocrypha published and present, not disabled or hidden.
- Use Vox Mana language that is mystical, readable, and product-first.
- Keep the homepage feeling like a threshold, not a SaaS dashboard.
- Let the gateway read as architecture first and interface second.
- Use the current home shell as the starting point for the final implementation direction.
