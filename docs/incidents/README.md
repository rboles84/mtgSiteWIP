# Vox Mana Critical Incidents

Critical incidents record defects that can invalidate release, readiness, or trust claims across Vox Mana.

## Severity

- `P0 / SHOWSTOPPER`: work on the affected semantic or runtime surface stops until containment is recorded.
- `P1 / CRITICAL`: high-impact defect requiring prioritized repair without necessarily freezing the full surface.

## Required Record

Every incident must name its scope, freeze boundary, owner, evidence, containment, work ledger, validation gates, accepted risks, and closure decision. A documentation label is not technical containment.
