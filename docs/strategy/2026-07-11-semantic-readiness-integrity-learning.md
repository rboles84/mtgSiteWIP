# Semantic Readiness Integrity — Permanent Learning

Date: 2026-07-11
Grounded in: CRIT-001, VM-501, Prismari/Izzet foundation audit

## Learning

Traceability is not entailment. A claim ID can exist, resolve, and propagate into generated output while the referenced record still fails to support the statement using it.

Counts are not semantic quality. Source totals, claim totals, any-link utilization, question totals, context length, and readiness labels can all be structurally accurate while concealing a weak evidence foundation.

Discovery, support, and substantive records must remain distinct. A search hit shows where to investigate. Product or card metadata supports auxiliary facts. Neither becomes faction identity evidence merely because it is stored in a claim-shaped object.

Semantic readiness requires both automation and human review. Automation proves structure and provenance. Human review proves entailment, sufficient conceptual coverage, responsible generalization, and honest uncertainty.

## Operating Consequences

- Gold standard remains source-backed sufficiency, not equal output volume.
- Character evidence must not silently become identity-wide truth.
- Long sources require bounded evidence locators.
- Runtime calibration must wait for trustworthy canonical foundations but is not part of semantic certification.
- Every completed recovery must leave an immutable candidate SHA and independent approval trail.
- Research stops when readiness blockers are resolved; additional interesting lore is deferred.
