# External Reviewer Two-Week Test

Date: 2026-07-03
Related card: VM-469
Status: Ready to run; blocked on five external reviewer responses

## Purpose

VM-452 defined a two-week external reviewer test to prove that Vox Mana makes sense outside the repo owner's head. This note turns that test into a recordable protocol and findings template. It does not claim the test is complete.

## Reviewer Prompt

Give each reviewer the public demo path and ask them to spend roughly five minutes with the site or case-study packet.

Demo path:

1. `https://voxmana.io/`
2. `https://voxmana.io/archscry/`
3. `https://voxmana.io/maze/`
4. `https://voxmana.io/strategium/`
5. `https://voxmana.io/apocrypha/`

Do not pitch account-backed deck saving, community deck publishing, legality checking, deckbuilding, or recommendation-engine behavior.

## Questions

Ask exactly these five questions from VM-452:

1. What is Vox Mana for?
2. What is it explicitly not trying to be?
3. Which part felt most trustworthy?
4. Which part felt most overbuilt or unclear?
5. Would this case study make you trust the builder's product/QA judgment?

## Pass Condition

Pass if at least four of five reviewers can:

- explain the product boundary in their own words after two minutes; and
- name one proof point beyond visual design.

Revise or kill the current case-study positioning if reviewers:

- assume Vox Mana is a deckbuilder, recommender, legality checker, or EDHREC substitute;
- admire the process but cannot explain the product;
- treat caveats as excuses rather than release governance.
