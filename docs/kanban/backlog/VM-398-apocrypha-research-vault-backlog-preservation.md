not approve publication, create a route, or expose working research files.

- Faction Files

- A future plan defines publication rules before any working material is surfaced publicly.
- Public UI copy distinguishes reviewed public references from internal working material.
- Raw notes, prompt traces, generated summaries, and unpublished captures are not exposed without review.
- Any future implementation receives its own pre-flight, design, source-governance, QA, and handoff pass.

## Out Of Scope

- Adding a live Research Vault route.
- Publishing PDFs, RTF files, HTML captures, generated notes, prompt traces, or raw working bundles.
- Changing Apocrypha Source Compass behavior.
- Changing placement logic, generated data, raw packets, Commander facts, or source claim ledgers.

## Context

VM-398 exists so the future Research Vault idea remains findable after the public
Phase 2 affordances are removed from `/apocrypha/`. The public Apocrypha route should
remain focused on live public URLs, source grouping, usage notes, and publication-boundary
