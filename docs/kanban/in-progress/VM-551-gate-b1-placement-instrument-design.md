## Risks

- Certified identity semantics are interpretive authority, not empirical evidence that a player answer predicts an identity.
- Committed player-language sources support understandable vocabulary and scenarios, not scoring weights or identity assignments.
- A small pilot cannot perfectly separate all 37 identities; insufficient and close outcomes must remain valid.
- Repeated constructs can create false evidence independence unless dependency groups are enforced.
- Theme, personal philosophy, deck behavior, table preference, experience, budget, and power expectation can be accidentally conflated.
