## Why it changed

Green existed only as an inactive identity shell. To complete the mono-color rollout and match the White/Black/Blue/Red practical mono bar, Green needed authored identity data plus model authoring so the adaptive engine could identify mono-Green directly instead of relying on Selesnya, Simic, Golgari, Gruul, Quandrix, or Witherbloom evidence.

## Decisions made

- Kept the pass source-first: Green authoring lives in `data/identity-layers.json` and `research/build-faction-artifacts.mjs`; generated runtime artifacts were produced by `npm run build:factions`.
- Verified Green Commander Compass choices against the local Scryfall commander index before adding them.
- Added only one dossier guidance data entry in `assets/js/commander-dossier.js`; no presenter behavior was rewritten.
- Distinguished mono-Green from:
  - `WG`: community identity, token/community mobilization, and collective care.
  - `UG` / Quandrix: adaptation, optimization, math, pattern logic, experimentation, and engineered improvement.
  - `BG` / Witherbloom: decay, rot, reclamation, life-death exchange, and resource economy.
  - `RG`: wild refusal, bodily force, rage/smash/pressure, and anti-civilization rupture.
- Did not change placement scoring semantics, adjacent-fit presentation, discovery-path contracts, or broader mono cleanup.
