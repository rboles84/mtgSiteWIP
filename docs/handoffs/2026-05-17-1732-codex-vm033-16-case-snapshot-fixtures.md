## What changed

- Expanded the fixed presentation snapshot fixture library from four starter cases to a 16-case baseline.
- Added five mono golden cases, five mono boundary cases, four guild golden cases, and two college golden cases.
- Renamed the starter pair-style case ids into the requested guild case ids while preserving the same live golden-path answer sets where applicable.
- Updated the focused snapshot validation test to assert the stable 16-case order and mono boundary family rails.
- Made snapshot artifact writes atomic and sequential, with CSV written first, so a locked generated CSV cannot leave JSON or Markdown partially written.

## Why it changed

The starter VM-033 harness proved the non-UI reporting path. This pass widens the source fixture baseline so snapshot JSON, CSV, and Markdown provide broader mono, guild, and college presentation coverage without using the browser or changing runtime behavior.

## Decisions made

- Used `runAdaptiveGoldenPath` output as the source of truth for golden fixtures.
- Kept boundary cases as fixed live paths that still resolve to the intended mono primary and keep adjacent family grouping inside the expected rails.
- Preserved raw adjacent labels exactly as returned by placement; family grouping remains debug-only in snapshot output and tests.
- Did not add any fixture-only scoring, presenter, or discovery-path behavior.
- Treated the Windows `EBUSY` CSV lock as a generated-artifact safety issue and hardened writes without changing the snapshot schema.

## Risks / uncertainties

- Some guild and college cases continue to surface existing dossier audit warnings; the harness records warning counts but this pass did not attempt source-data cleanup.
- Blue boundary needed a broader live route with a Crucible step to keep mono Blue primary while exposing Prismari/Quandrix-family adjacency.
- Red and Green boundary cases remain relatively decisive because their mono gate paths are strong; they still provide adjacent-family drift coverage but are less knife-edge than White or Blue.
- If the live adaptive selector changes, these fixed fixtures should fail fast by question id, answer index, or answer title.
