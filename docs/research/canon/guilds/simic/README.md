# Simic Vox Mana Bundle

Generated: 2026-05-18

This bundle provides a Simic Combine data pack for Vox Mana modeling and UI implementation.

## Files

- `simic_structural_matrix.csv` — tabular card matrix with 90 canonical / Simic-aligned rows.
- `simic_structural_matrix.json` — same matrix with metadata and source anchors.
- `simic_animation_spec.json` — Simic-specific animation and UI motion grammar.
- `simic_translation_layer_functions.js` — JS helper functions preserving shared names: `Detain`, `Override`, `ConstraintField`, `AccretionEngine`.
- `simic_translation_layer_functions.json` — function contracts and examples.
- `simic_narrative_taxonomy.md` — human-readable taxonomy for writing and UX.
- `simic_narrative_taxonomy.json` — structured taxonomy for ingestion.

## Canonical Policy

Rows are selected as Simic-watermarked, Simic-named, Simic leader/founder, official guild infrastructure, or mechanically central Simic-era cards. This is a modeling artifact, not an exhaustive Oracle export.
