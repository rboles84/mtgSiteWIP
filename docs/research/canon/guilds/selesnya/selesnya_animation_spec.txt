## 1. Overview

This document defines the visual language, motion system, and animation parameters for Selesnya-themed card interactions. The Selesnya Conclave's identity is rooted in communal growth, natural harmony, and collective strength. Animations reflect organic, living, interconnected systems — not mechanical or abrupt motion.

## 3. Typography Motion

- **Card Name:** Fade-in with a gentle upward drift (8 px over 300 ms, ease-out-cubic).
- **Mana Cost:** Each pip pops in sequentially with a 40 ms stagger, scale 0.7 → 1.0.
- **Oracle Text:** Reveal line-by-line with 20 ms per line offset, opacity 0 → 1 over 180 ms.

## 5. Particle Systems

### 5.1 Summon Leaves
- **Emitter:** Ring burst centered on card art origin.  
- **Count:** 24–48 particles.  
- **Shape:** Stylized 5-pointed leaf, 6–14 px.  
- **Colors:** Grove Canopy → Elder Oak gradient.  
- **Lifetime:** 600–900 ms.  
- **Velocity:** Radial outward 80–160 px/s, with -Y gravity bias (-30 px/s²).  
- **Rotation:** ±360° random spin.  
- **Opacity:** 1.0 → 0.0 over last 30% of lifetime.

### 5.2 Lifelink Pulse
- **Emitter:** Point at creature center, fires on damage-dealt event.  
- **Count:** 1 large pulse + 8 sparklets.  
- **Shape:** Soft radial gradient circle.  
- **Colors:** Vitality Pink → Conclave Ivory.  
- **Lifetime:** 480 ms pulse, 300 ms sparklets.  
- **Velocity:** Upward drift 20 px/s.  
- **Scale:** 1.0 → 2.4 → 0.0 (Organic Rise easing).

### 5.3 Populate Fractal
- **Emitter:** Center of source token.  
- **Behavior:** Ghosted copy of token art fades in at 80% opacity, drifts 60 px to a target slot.  
- **Duration:** 700 ms total (400 ms travel + 300 ms materialize at destination).  
- **Particles:** 16 small leaf motes accompany the ghost image.

### 5.4 Anthem Halo
- **Emitter:** Global overlay across all friendly creatures.  
- **Shape:** Expanding ring per creature.  
- **Colors:** Sun-Dappled Gold, 70% opacity.  
- **Expansion:** 0 → 120% card width over 600 ms, then fade 600 ms.  
- **Stagger:** 50 ms per creature in play order.

### 5.5 Token Summoning Motes
- **Emitter:** Battlefield target slot.  
- **Count:** 32 motes.  
- **Colors:** Spirit Opalescent → Conclave Ivory.  
- **Behavior:** Converge inward to center from radius 200 px over 500 ms, then burst outward as token art renders.

## 6. State Machine — Common Selesnya Actions

```
[IDLE]
  │  trigger: summon_event
  ▼
[SUMMON_ENTER]  — Organic Rise, 400 ms, leaf particles
  │  on_complete
  ▼
[ACTIVE_IDLE]  — Slow Breathe loop (scale 1.00 ↔ 1.02, 2800 ms)
  │
  ├─ trigger: buff_applied  ──▶ [BUFF_FLASH]  — Snap Emphasis 240 ms, +1/+1 counter pop
  │                               └─ on_complete ──▶ [ACTIVE_IDLE]
  │
  ├─ trigger: anthem_resolved ──▶ [ANTHEM_GLOW]  — Gold halo ring 1200 ms
  │                                └─ on_complete ──▶ [ACTIVE_IDLE]
  │
  ├─ trigger: populate_trigger ──▶ [POPULATE_CLONE]  — Ghost copy drift 700 ms
  │                                 └─ on_complete ──▶ [ACTIVE_IDLE]
  │
  ├─ trigger: lifelink_damage ──▶ [LIFELINK_PULSE]  — Pink pulse 480 ms
  │                                └─ on_complete ──▶ [ACTIVE_IDLE]
  │
  ├─ trigger: tap_action ──▶ [TAPPED]  — 90° clockwise rotate, 240 ms, Gentle Settle
  │                            └─ trigger: untap ──▶ [ACTIVE_IDLE]
  │
  └─ trigger: death ──▶ [DEATH_DISSOLVE]  — Leaf scatter outward 700 ms, opacity 1→0
                          └─ on_complete ──▶ [REMOVED]
```

### Convoke-like Interaction
When multiple creatures tap together for a convoke cost:
1. Each tapping creature emits a golden thread particle toward the casting card (staggered 80 ms each).
2. Threads converge at the casting card's center over 600 ms.
3. Casting card pulses with Anthem Halo on convergence.
4. All tapping creatures immediately enter [TAPPED] state.

## 7. Example Animation Sequences

### Sequence A: Creature Summon (e.g., Rootborn Sentinel)
```
T+0ms    Card slides in from bottom edge (Y: +200px → 0, Organic Rise, 400ms)
T+0ms    Leaf particles burst (summon_leaves preset)
T+200ms  Card art fades from white flash → full color (opacity 0.4→1.0, 300ms)
T+400ms  P/T badge pops in (scale 0.5→1.05→1.0, Snap Emphasis, 240ms)
T+640ms  [ACTIVE_IDLE] loop begins
```

### Sequence B: Populate Resolution
```
T+0ms    Source token emits fractal ghost copy
T+0ms    16 leaf motes accompany ghost
T+400ms  Ghost arrives at destination slot, opacity reaches 80%
T+400ms  Token motes converge inward at destination (Spirit Opalescent)
T+700ms  Token fully materializes; leaf burst at destination
T+800ms  All elements settle into [ACTIVE_IDLE]
```

### Sequence C: Anthem Buff (+1/+1 to all)
```
T+0ms    Global overlay activates
T+0ms    Staggered gold rings expand per creature (50ms stagger)
T+600ms  All rings reach full expansion
T+600ms  Rings fade over 600ms
T+1200ms P/T values tick up with Snap Emphasis per creature (50ms stagger)
T+1500ms All creatures return to [ACTIVE_IDLE]
```

## 8. Accessibility Notes

- **Reduced Motion Mode:** When system `prefers-reduced-motion` is active:
  - All particle systems are disabled.
  - Transitions collapse to simple cross-fades at 50% of normal duration.
  - Halo rings replaced by a static border highlight for 1 second.
  - No scale transforms above 1.05.
- **Color Contrast:** All UI text on Bark Scroll background meets WCAG AA (4.5:1 minimum).
- **Timing Safety:** No animation loop exceeds 3 Hz flicker rate (safe for photosensitivity).
- **Screen Reader:** All animation state changes emit aria-live region updates describing the game event in plain language.
- **Alternative Indicators:** Buff/anthem states use both color and iconographic badge (not color alone).
