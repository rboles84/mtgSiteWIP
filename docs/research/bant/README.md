## Research Standard

This package applies a strict source hierarchy and separates information into the following categories:

- **Confirmed Canon** — Directly stated in an official Wizards story, mechanics article, plane page, or official product source.
- **Card-Supported** — Directly supported by official card text (oracle text or flavor text) via Gatherer or Scryfall.
- **Rules-Supported** — Directly supported by official release notes, mechanics articles, or the Comprehensive Rules.
- **Official Summary** — Stated in an official Wizards summary or design article.
- **Repository Archive Supported** — Supported by the polarkac/MTG-Stories GitHub archive, which contains copies of official story text.
- **Supported Interpretation** — Reasonable synthesis of cited evidence, labeled as interpretation. Not presented as fact.
- **Alara Context** — Relevant to Alara broadly, not necessarily unique to Bant.
- **Bant-Adjacent Discovery** — Appears in secondary sources (MTG Wiki, MTGLore) but not yet verified in a primary source. Not included in the dossier body unless upgraded.
- **Unverified / Not Found** — Could not be confirmed in reviewed materials.

All factual claims include source IDs. Claims not traceable to a reviewed source are either excluded or clearly labeled as unverified.
