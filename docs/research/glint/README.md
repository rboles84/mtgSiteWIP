## Naming Authority Note

Four-color combinations should not be described as having settled universal official MTG names. In this packet, `GLINT` is Vox Mana's Nephilim-derived public expression and research label for the UBRG, non-White lane. `Chaos` is the Commander 2016 mechanical/theme alias for the same color quadruple. Future docs may use `Glint / Chaos` as a paired frame, but must not state that either label is the official, exclusive, or universally accepted MTG name for UBRG.
