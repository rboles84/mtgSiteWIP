Feature 01

Modern Theming

CSS custom properties combined with OKLCH color space, color-mix(), and relative color syntax for perceptually uniform, future-ready theming systems.

OKLCH Color Space

OKLCH provides perceptually uniform colors. Unlike RGB/HSL, equal lightness values appear equally bright to the human eye.
Example:
--gold: oklch(76% 0.14 75);
This gold uses OKLCH

color-mix() Function

Mix colors directly in CSS without preprocessing. Perfect for creating derived colors like hover states and transparency variants.
Example:
color-mix(in oklch, var(--gold) 32%, transparent)

Theme Switching

Use data attributes and CSS custom properties for instant theme changes. Try the theme buttons in the header above!
HTML:
<body data-theme="violet">
CSS:
body[data-theme="violet"] { --accent: var(--violet); }

Feature 10

Masking + Clipping

Create unique shapes with clip-path and mask-image for parchment edges, sigil cutouts, and decorative boundaries.

Clipped Polygon Shape

Parchment Edge Effect

This container uses SVG mask-image to create a torn parchment edge effect. Perfect for fantasy-themed interfaces and decorative panels. The mask creates an organic, hand-crafted appearance.

Clip-Path & Mask-Image

clip-path cuts shapes with vectors, while mask-image uses images/gradients for transparency. Both are powerful tools for creative layouts.
Clip-Path:
clip-path: polygon(0 0, 100% 0, 100% 85%, 50% 100%, 0 85%);
Mask-Image:
mask-image: url('path/to/mask.svg');
Feature 11

Container Queries

Component-based responsiveness that adapts to container size, not viewport. Enables truly modular, reusable components.

Responsive Components

All example cards on this page use container queries. Resize your browser to see them adapt independently based on their own width, not the viewport.
CSS:
container-type: inline-size; container-name: card;
@container card (min-width: 400px) { padding: 2.5rem; }

Wide Container

Feature D

Cascade Layers + Nesting

Organize styles with @layer for predictable specificity. Reduces conflicts and makes CSS architecture more maintainable.

Layer Organization

Define layer order once, then styles cascade predictably. Lower layers can't override higher layers regardless of specificity.
CSS:
@layer base, components, utilities, effects;
