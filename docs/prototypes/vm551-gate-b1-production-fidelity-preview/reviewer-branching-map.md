# Reviewer Branching Map

## Boundary

All free-answer journeys begin with the same four approved Gate observations: C01 initiative posture, C02 resource visibility, C03 disruption response, and C04 advantage tempo. Only after all four answers exist does the preview select an unresolved Hall construct.

The map is deterministic owner-review scaffolding, not scoring, calibration, identity support, exclusion, or a final adaptive algorithm. A single Gate answer never names or locks an identity branch.

Every branch asks two or three adaptive/targeted behavioral questions, for seven total except the six-question fallback. No free-answer branch introduces the identity lens.

## Exact adaptive-feel acceptance

- `visible-recovery-growth`: Set the pace → A board people can see → A way to rebuild → A little every turn → C09 Repeatability.
- `visible-burst-pressure`: Set the pace → A board people can see → Less exposed in the first place → One turn that changes the game → C07 Pressure.
