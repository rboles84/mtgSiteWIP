# VM-551 Repeated-Signal and Dependency Audit

`repeated-signal-dependency-audit.csv` records eleven controlled audit groups: procedure/order, protection/duty, community/belonging, knowledge/deliberation, experiment/invention, expression/performance, agency/leverage, decay/renewal, growth/nature, speed/action, and history/memory.

These are not empirical correlation groups. No player-response data exists to estimate statistical correlation. Accurate descriptions are:

- repeated construct;
- duplicated authored signal;
- overlapping interpretation;
- unmodeled dependency;
- potential double-count.

For each group the CSV identifies exact questions/answers, stages, identities, suppressions, maximum strong-hit contribution observed in one valid path, Gate-to-later-stage overlap, stopping/confidence influence, explanation risk, and required handling.

## Findings

1. Several answers can encode the same underlying player observation across Gate, Hall, and Crucible.
2. The engine adds each authored effect independently; it has no controlled dependency group or cap.
3. Repeated contributions can change the rank vector, top-two gap, stopping decision, and whether a Crucible question appears.
4. Result copy lists selected signals as separate reasons even when they are overlapping interpretations of one construct.
5. Gate evidence can be counted again in later stages for cross-stage groups.

The first pilot must assign a controlled construct/dependency ID to every active answer. Repeated instances must be capped, grouped, or explicitly modeled; confidence/evidence amount must count independent evidence units rather than raw answer count. Empirical dependence can be estimated only after player-response data exists.
