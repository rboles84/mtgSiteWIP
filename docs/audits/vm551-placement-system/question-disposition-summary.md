## Interpretation boundary

CECOS draft.4 treats player-facing questions as derived instruments, not primary player language. Question derivation therefore needs an identified observation set, intended distinction, known false positives/negatives, neighboring interpretations, wording transformations, and visible unknown/mixed handling. The current live model supplies none of those answer-level contracts.

The first pilot must not attempt to repair all 113 questions. It should select the smallest evidence-derived set that can test owner-approved high-risk contrasts, preserve representational failure, and emit insufficient/close results. All other questions remain excluded pending evidence and comprehension review.
