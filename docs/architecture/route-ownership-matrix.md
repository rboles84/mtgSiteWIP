# Route Ownership Matrix

This matrix records what each public route owns, what shared systems it consumes, and what future branches must avoid changing without explicit scope.

This is an audit artifact, not an implementation branch. The generic web development research aligns with Vox Mana's current direction through semantic HTML, OKLCH tokens, container queries, reduced motion, native platform patterns, and route-level polish. These should remain selective enhancements, not a repo-wide modernization mandate.

## Audit Scope

- Reviewed public route HTML, route CSS, route JS entrypoints, shared CSS/JS, frontend validators, smoke tests, manual QA docs, project atlas, and generic webdev research.
- Public routes covered: `newIndex2.html`, `archscry/index.html`, `maze/index.html`, `strategium/index.html`, `apocrypha/index.html`, `library/index.html`, `privacy/index.html`, and `terms/index.html`.
- Runtime code, generated data, visual baselines, Supabase schema, placement logic, precon ranking, and route markup were not changed.

| Session and Supabase bridge | `assets/js/shared.js` | Archscry, Maze | Owns `VM_SESSION`, Supabase client access, saved placement persistence, pending save flow, and archived terminal helpers. |
| Chart runtime | `assets/js/graph.js` | Home, Archscry | Large vendored Chart.js runtime. It is local, not CDN-loaded, but still heavy. |

## Follow-Up Card Targets

- Route-contract documentation is delivered by VM-143 and this matrix.
- Stale preview/archive candidates should be verified before archive work; never delete docs/assets permanently.
- Legal page CSS extraction should stay presentation-only and preserve policy text.
- CDN/font dependency review should separate privacy/performance analysis from broad architecture change.
- Large CSS/JS reduction should be route-by-route with visual harnesses, not shared-system churn.

## Current Verification Baseline

- `npm run lint:html` validates public script deferral, image sizing, landmarks, topbar navigation semantics, Maze modal semantics, route-local CSS extraction, Library alias safety, and legal nav targets.
- `npm run lint:js` syntax-checks the main frontend route scripts and guards against inline handler patterns/body-level HTML injection.
- `npm run test:frontend-smoke` verifies critical home, Maze, Archscry, Library alias, Privacy, and Terms route contracts.
- `npm test` covers placement, parser, builder, syntax translation, Maze metadata, precon artifacts, Archscry dossier follow-ups, and presentation snapshots.
- `npm run dossier:audit` currently reports warnings but no failures; treat warnings as known dossier quality work, not a route ownership blocker.
